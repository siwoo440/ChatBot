# GPT 이미지 요청문

그림이 필요할 때 GPT(이미지 생성)에 넘길 말을 여기에 적는다. 사용자가 GPT로 만든 그림을 가져오면 크기·형식을 맞춰 넣고 상태를 고친다.

- 공통 조건: 사람·글자·로고·워터마크 없음, 가로 3:2(1536×1024), 중요한 것은 가운데 3분의 1 안(스토리 표지에서는 화면에 따라 잘려 보임. 대화 화면에서는 응답 아래에 원래 비율 그대로 작게 보임)
- 그림체: 기존 캐릭터 그림과 맞는 반실사 애니메이션 일러스트(세밀한 채색, 부드러운 영화 같은 조명)
- 받은 뒤 처리: 1200×800 WebP(품질 84)로 바꿔 `public/images/scenes/`에 넣는다. 경로는 `src/lib/assets/scene-paths.ts` 한 곳에서 관리하고, 경로가 바뀌면 `upgradeScenePath`에 예전 경로를 추가해 저장 데이터를 불러올 때 함께 바뀌게 한다.

## 요청문

공통 머리말(네 장 모두 앞에 붙인다):

> 사람이 없는 배경 일러스트를 그려 줘. 반실사 애니메이션 일러스트 그림체, 세밀한 채색, 부드럽고 영화 같은 조명. 가로 3:2 비율(1536×1024). 중요한 사물은 화면 가운데 3분의 1 안에 두고, 양옆은 잘려도 괜찮게 구성해 줘. 사람, 글자, 로고, 워터마크, 테두리는 넣지 마.

1. 새벽의 편지: 새벽빛이 스며드는 오래된 고딕 양식 도서관 안. 천장까지 닿는 책장, 높은 아치형 창 너머로 보랏빛과 푸른빛이 섞인 새벽 하늘. 가운데 나무 책상 위에 펼쳐진 두꺼운 책과 작은 촛불, 그 위 공중에 편지와 종이 조각 여러 장이 은은하게 빛나며 떠다닌다. 보라·남색 중심에 촛불의 따뜻한 금빛.
2. 비 오는 교실: 방과 후 아무도 없는 고등학교 교실. 큰 창밖으로 비가 내리고 유리창에 빗방울이 맺혀 흐른다. 가운데 창가 책상 하나와 의자, 책상 옆에 세워 둔 접은 우산 하나. 흐린 청회색 바깥빛과 교실 안의 따뜻한 전등빛이 섞인다. 차분하고 조금 쓸쓸한 분위기.
3. 달빛 기록관: 둥근 유리 천장으로 달빛이 쏟아져 들어오는 오래된 기록 보관소. 벽을 따라 끝없이 이어진 서류 서랍과 두루마리 선반, 가운데 원형 열람대 위에 펼쳐진 기록 책. 달빛 줄기 속에 먼지와 작은 빛 알갱이가 떠 있다. 은빛·청색 중심에 옅은 보라.
4. 기본 장면: 어떤 이야기에도 어울리는 조용한 방. 해 질 녘 큰 창으로 보랏빛과 분홍빛 노을이 들어오고, 얇은 커튼이 살짝 흔들린다. 가운데 작은 둥근 탁자 위에 찻잔 하나와 덮어 둔 책. 따뜻하고 차분한 분위기, 보라·분홍·살구색.

### 5번: 친구 초대 그림 (2026-10-03 요청)

> 사람이 없는 일러스트를 그려 줘. 반실사 애니메이션 일러스트 그림체, 세밀한 채색, 부드럽고 영화 같은 조명. 가로 3:2 비율(1536×1024). 보랏빛과 분홍빛이 섞인 저녁 하늘 아래, 화면 가운데에 리본이 풀리며 열리는 선물 상자와 그 위로 떠오르는 반짝이는 초대장 카드 한 장. 상자에서 작은 별과 빛 알갱이, 말풍선 모양의 은은한 빛이 퍼져 나간다. 따뜻하게 환영하는 분위기, 보라·분홍·살구색 중심. 중요한 사물은 화면 가운데 가로 띠 안에 두고, 위아래 20%씩은 잘려도 괜찮게 구성해 줘(메신저 미리보기에서 가로로 길게 잘린다). 사람, 글자, 로고, 워터마크는 넣지 마.
